# EvalLoop docs

Everything written *about* the project. Code lives at the repo root (`evalloop/`, `tests/`,
`knowledge rules/`, `decisions/`).

| Folder | Holds |
|---|---|
| [architecture/](architecture/) | System design: `ARCHITECTURE.md`, `AGENT.md`, `USER_EXPERIENCE.md` |
| [planning/](planning/) | Roadmap: `PLAN.md`, `TASKS.md`, `DEVELOPMENT_PLAN.md` |
| [tickets/](tickets/) | Ticket + prompt packs per epic (E0–E3) |
| [reports/](reports/) | Per-stage (`S*`) and per-ticket (`EL-*`) completion reports |
| [gates/](gates/) | Gate review packets (0, 1, V) and the rendered Gate 0 plans |
| [misc/](misc/) | Non-project files |

Decision records (`EL-NNN`) are at the repo root under [`decisions/`](../decisions/).
Runnable examples and the Gate V evidence driver are under [`examples/`](../examples/) and
[`tools/`](../tools/).
